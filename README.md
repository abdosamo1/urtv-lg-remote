# ريموت تلفزيونك · urtv-lg-remote

تطبيق أندرويد صغير لموبايل قديم بيضل بالبيت. وقت الأذان (مواقيت الجامع من Mawaqit):

1. يشغّل شاشة LG إذا كانت مطفية (Wake-on-LAN)
2. يلغي الكتم ويحط الصوت على 10
3. يفتح تطبيق **تلفزيونك** (webOS) فوق أي شي شغّال، وهو بيشغّل الأذان
4. بعد الأذان: يرجّع الصوت، ويطفي الشاشة إذا كانت مطفية، أو يرجّع التطبيق اللي كان شغّال

وكمان يمدد وضع المطوّر على الشاشة كل يوم (برمز الجلسة).

بيتواصل مع الشاشة بنفس واجهة LG اللي بيستعملها تطبيق ThinQ (SSAP على المنفذ 3001).

كل push على `main` بيبني الـ APK وبينشره بـ [Releases › latest](../../releases/tag/latest).

> مفتاح التوقيع بالمستودع (`app/keystore.b64`) لهالتطبيق الشخصي بس، حتى كل نسخة جديدة تنزل فوق القديمة.
